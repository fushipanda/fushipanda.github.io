# fushipanda.github.io

Personal website built with [MkDocs](https://www.mkdocs.org/) and the [Material theme](https://squidfunk.github.io/mkdocs-material/).

## View Site

https://fushipanda.github.io/

## Development

```bash
pip install mkdocs mkdocs-material
mkdocs serve
```

## Deployment

Push to `gh-pages` branch → auto-deploys via GitHub Actions.
